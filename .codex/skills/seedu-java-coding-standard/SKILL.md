# SE-EDU Java Coding Standard

Apply the project standard to every Java file touched by a task. Before editing or reviewing Java code, read [references/rules.md](references/rules.md) completely.

When changing Java code:

1. Preserve the user's requested behavior while applying every relevant rule.
2. Inspect the whole touched file, not only changed lines, and fix clear violations that are reasonably within scope.
3. Use the Google Java Style Guide for topics not covered by the project rules.
4. Keep tests subject to the same rules, except that public test classes and methods do not require Javadocs.
5. Report any rule that cannot be followed because it conflicts with behavior, generated code, or an external interface.

The authoritative source is the [SE-EDU Java coding standard (basic + intermediate)](https://se-education.org/guides/conventions/java/intermediate.html). If the local reference and source differ, follow the authoritative source and update the reference.
