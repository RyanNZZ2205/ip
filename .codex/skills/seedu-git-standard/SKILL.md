# SE-EDU Git Standard

Apply the project standard whenever a task involves a branch name or commit. Before proposing, reviewing, or creating either, read [references/rules.md](references/rules.md) completely.

When working with Git:

1. Check branch names and commit messages against every applicable rule.
2. Inspect the actual change when available so the commit subject and body describe its purpose accurately.
3. Treat a body as required for every non-trivial commit, even when the subject is self-explanatory.
4. If a proposed name or message violates the standard, correct it or explain the violation before use.
5. Preserve repository-specific Git requirements and the user's authorization boundaries. This skill does not grant permission to create a branch, commit, tag, or push.

The authoritative source is the [SE-EDU Git conventions](https://se-education.org/guides/conventions/git.html). If the local reference and source differ, follow the authoritative source and update the reference.
